## 絶対に守ること

1. **「新しいデプロイ」を作らないこと。** 「デプロイを管理」→ 既存デプロイの鉛筆 →
   バージョン「新バージョン」→「デプロイ」で更新し、デプロイIDが変わっていないことを確かめる。
2. **貼り替えるのは `コード.gs` の1ファイルだけ。** `Form.html`・トリガー・スクリプト プロパティには触らない。
3. **貼り替える前に、今のバージョン番号を控えること**（戻すときに使う）。
4. **フォームから送信しないこと。** シフトの送信・修正・削除はしない。
   スプレッドシートのメニュー（「翌月へ切り替え」など）や関数の実行もしないこと。
5. 想定と違うことがあれば、勝手に判断せず止まって報告すること。

## コピーの仕方（非公開リポジトリから）

1. 下に書いた GitHub のURLを開く（ログインしていないと 404 になる）
2. ファイルの中身が表示されている枠の右上にある **「Copy raw file」**（2枚重ねの紙のアイコン）を押す
   - 見当たらない場合は「Raw」を押して開いたページで **Ctrl+A → Ctrl+C**
3. Apps Script で `コード.gs` を開き、**Ctrl+A → Ctrl+V**
4. 確かめる
   - 最後の行番号が、下に書いた行数と同じ（最後に空行が1行増えるのは問題なし）
   - 1行目と最後の行が、下に書いたものと同じ
5. 保存（Ctrl+S）。赤いエラーが出たら止まって報告
