# シフト送信のしくみ（設定手順）

スマホの `shift.html` から送った内容を、シフト表のスプレッドシートに直接書き込むための設定です。
**エンジニアでなくてもできます。全部で10分ほどです。**

```
スマホ（shift.html）  ──送信──▶  Apps Script（shift-api.gs）  ──書き込み──▶  シフト表
                                                              └─記録──▶  送信ログ
```

対象スタッフ：**福岡・清田・福山・古川**（`shift.html` の `STAFF` と `shift-api.gs` の `ALLOW_STAFF` を書き替えれば増減できます）

---

## 1. スプレッドシートにスクリプトを貼る

1. シフト表のスプレッドシートを開く
2. 上のメニューから **「拡張機能」→「Apps Script」**
3. 最初から入っている `function myFunction() {}` を全部消す
4. このフォルダの **`shift-api.gs` の中身をすべてコピーして貼り付け**
5. 左上のフロッピーマーク（保存）を押す

## 2. 合言葉を決める（推奨）

貼り付けたコードの上のほうにある行を書き替えます。

```js
var TOKEN = '';        →   var TOKEN = 'sieg2026';   // 好きな文字列でOK
```

URLを知られただけでは送信できなくなります。**あとで `shift.html` にも同じ文字列を入れます。**

## 3. ウェブアプリとしてデプロイする

1. 右上の **「デプロイ」→「新しいデプロイ」**
2. 歯車マーク → **「ウェブアプリ」** を選ぶ
3. 設定を次のようにする
   - 説明：`シフト送信API`
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 「デプロイ」を押す
5. **アクセスを承認**（「詳細」→「（プロジェクト名）に移動」→「許可」）
6. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/……/exec`）をコピー

## 4. shift.html にURLを貼る

リポジトリの `shift.html` を開き、`<script>` のいちばん上を書き替えます。

```js
var SHIFT_API   = 'ここにGASのデプロイURLを貼る';   →   コピーしたURL
var SHIFT_TOKEN = '';                              →   手順2で決めた合言葉
```

保存してプッシュすると、数分後に GitHub Pages に反映されます。

## 5. 動作確認

- ブラウザで `……/exec?action=ping` を開き、`{"ok":true,...}` が出れば設置成功
- Apps Script の画面で関数 `testFindRows` を実行すると、**シフト表・日付の行・各スタッフの行が正しく見つかっているか**が実行ログに出ます

---

## 直したいときは

| やりたいこと | 直す場所 |
|---|---|
| スタッフを増やす／減らす | `shift.html` の `STAFF`、`shift-api.gs` の `ALLOW_STAFF` |
| 取引先・キャリアの選択肢 | `shift.html` の `CLIENTS` / `CARRIERS` |
| よく使う開催場所 | `shift.html` の `PLACES` |
| 送信ログのシートを固定したい | `shift-api.gs` の `LOG_SHEET_NAME` |

**コードを直したら、必ず「デプロイ」→「デプロイを管理」→ 鉛筆マーク → バージョンを「新バージョン」にして更新してください。**
これをしないと古いコードのまま動きます。

---

## しくみのメモ

- シフト表の行・列は決め打ちしていません。A列からスタッフ名を探し、その下の
  `取引先` / `キャリア／店舗` / `開催場所` / `ホテル` の行を見出しで判別し、
  `日付` の行から日にちの列を探して書き込みます。行や列が増えても動きます。
- 送信は連続した日を1件にまとめて（例：11日〜18日）ログに残ります。既存の
  「日時・操作・名前・年・月・開始日・終了日・取引先・キャリア・開催場所・ホテル」の
  ログシートをそのまま使います。
- 「取り消す」で送ると、その日のセルを空にして、ログには `削除` として残ります。
- 集計レポートのシートには触れません（これまでどおりの更新方法のままです）。
