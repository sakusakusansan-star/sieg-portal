# fighters — 戦闘力のキャラ画像

戦闘力の画面（`power.html`）で選べるキャラの画像を置くフォルダです。

## 置き方（パソコンのブラウザから）

1. このフォルダを GitHub で開く
   https://github.com/sakusakusansan-star/sieg-portal/tree/main/fighters
2. 右上の「Add file」→「Upload files」
3. 画像を **`01.png` 〜 `12.png`** の名前にしてから、ドラッグして入れる
4. 下の「Commit changes」を押す（1〜2分で画面に出ます）

- 背景が透明な PNG がきれいに見えます。縦長（3:4 くらい）がおすすめです。
- 画面では、同じ番号の **軽い版（`01.webp` 〜 `12.webp`）** を使います（PNG は大きいので、そのままだと重くなるため）。
  - **PNG を差し替えたら、同じ番号の `.webp` を消してください。** 消すと、その番号は PNG で出ます（正しく出ますが少し重い）。
  - 軽い版は、Claude に「fighters の webp を作り直して」と頼めば作ります（長い辺 640px・WebP）。
- 画像が無い番号は、シルエットと「？」が出ます。
- キャラの名前は `power.html` の `NAMES` を書き換えます。

## 気をつけること

このフォルダの画像は、アドレスを知っていれば誰でも見られます。
権利のある画像は、その使い方（公開のウェブサイトに置くこと）まで許可されているか確かめてから入れてください。
